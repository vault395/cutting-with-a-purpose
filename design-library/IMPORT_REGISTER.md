# Vault 395 — Design Library Import Register

This register tracks artwork to import from the Mirror Design project into the Cutting With a Purpose customer catalog. **This is an inventory, not the artwork files.** Do not publish previews until original assets have been located and approved.

## Library rules
- Customer catalog: approved preview images only, subtle watermark, no laser masters.
- Private masters: maintain outside this public GitHub repository. Include source artwork, reverse-etch ready versions, square and rectangular versions, and revision history.
- Do not publish Disney-related designs.
- Status `pending-assets` means no artwork has been transferred or verified.

## Import workflow
1. Locate original artwork files and match them to design names.
2. Preserve originals and laser masters in a **private** location, not this public repo.
3. Verify artwork corrections and aspect-ratio variants.
4. Select approved public previews and apply the agreed light watermark.
5. Add catalog entries to the existing website, retaining existing ordering functionality.
6. Confirm previews, mobile layout, and exclusion rules before publication.
