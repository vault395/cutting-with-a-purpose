Aviso de privacidad de Vault 395

Última actualización: 24 de octubre de 2026

Vault 395 / Cutting With a Purpose utiliza este sitio para mostrar productos y recibir solicitudes de pedidos personalizados. Contacto: shopvault395@gmail.com.

Datos que proporcionas

Al solicitar una cotización, recibimos los datos que ingresas, como nombre, correo electrónico, tamaño y acabado del espejo, preferencia de entrega, código postal cuando corresponda, instrucciones del diseño y notas. Las imágenes seleccionadas para la vista previa no se cargan automáticamente con el formulario; debes enviarlas por correo electrónico por separado si deseas que las revisemos.

Uso de la información

Utilizamos estos datos para responder consultas, preparar cotizaciones, comunicarnos sobre la aprobación del diseño, coordinar la producción y la entrega y mantener registros comerciales. No incluyas datos de tarjetas de pago ni información personal sensible en las notas o instrucciones.

Servicios externos

El sitio se aloja en GitHub Pages. Formspree procesa las solicitudes enviadas directamente. Supabase gestiona los «me gusta» de la galería. Un servicio externo de conteo de visitantes puede procesar datos técnicos al cargar el contador. Estos proveedores pueden procesar información como direcciones IP y datos del navegador según sus propias políticas. Las imágenes enviadas por correo se procesan mediante nuestro proveedor de correo. Las calculadoras de envío llevan a sitios externos.

Almacenamiento del navegador y visitas

Utilizamos almacenamiento del navegador para el idioma, los diseños favoritos y para limitar conteos repetidos de visitas. Esto no representa un conteo exacto de personas únicas. Puedes borrar los datos del sitio desde tu navegador, pero perderás tus preferencias guardadas.

Compartir y conservar datos

No vendemos los datos de las solicitudes a anunciantes. Compartimos información con los proveedores necesarios para operar el sitio y gestionar las solicitudes, o cuando la ley lo requiera. Podemos conservar registros para completar pedidos, contabilidad, resolver disputas y cumplir obligaciones legales. Los períodos específicos de conservación de los proveedores pueden variar y deben verificarse.

Consultas y solicitudes

Escribe a shopvault395@gmail.com para consultar, corregir o solicitar la eliminación de tus datos cuando corresponda. Es posible que debamos conservar ciertos datos por obligaciones legales o comerciales.
